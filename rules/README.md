# rules/

Каждый файл — markdown с правилами поведения LLM для одного домена.

Сейчас правила inlined в `supabase/functions/_shared/rules.ts` (так проще
деплоить). Эта папка — план для будущего: когда правила вырастут, переносим
их сюда и подгружаем в edge-функции через bundling или fetch из публичного
URL репозитория.

Текущие домены:

- `global.md` — общие правила для всех сообщений
- `work_sessions.md` — рабочие сессии, проекты, алиасы
- `activity.md` — спорт (серф, пиклбол, муай-тай, болдеринг, зал, бег, хайк)
- `nutrition.md` — еда, оценка калорий, фото
- `finance.md` — деньги, валюты, категории
- `body_metrics.md` — вес, пульс, HRV
- `substances.md` — модафинил, кофе, алкоголь
- `sleep.md` — сон (wake/sleep_time, sleep_hours)

Когда добавляешь новый домен:

1. Создай файл `<name>.md` тут (для документации).
2. Добавь константу в `_shared/rules.ts` с тем же содержимым.
3. Добавь ключ в `DOMAIN_RULES`.
4. Если домен должен прокидываться по умолчанию — добавь в `ALL_DOMAINS`.
